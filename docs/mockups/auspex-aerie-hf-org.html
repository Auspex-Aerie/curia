Inside curia-grounding-config (recipe only)

curia-grounding-config/ ├── README.md # card: what Curia uses by default ├── config.json # product, version, stack pointers └── stack.defaults.json # semantic / rerank / router / fusion # Does NOT contain multi-GB ColBERT or Jina weights # Those stay at colbert-ir/* and jinaai/* — prefetch locally
Naming rule: product + role in the id (curia-grounding-config). Thresholds, revisions, RRF/graph knobs live in JSON — never in the repo name.

What we do not put under Auspex-Aerie

  • Re-uploads of colbert-ir/colbertv2.0, Jina v3, MiniLM — cite + prefetch
  • Git LFS blobs inside application git repos
  • Kitchen-sink names encoding every hyperparameter
  • A lone CodeRAG org that hides netflow / domain / brand / compression lines
Operators: uv run curia-prefetch-rag fills the local HF cache from upstream Hub ids (see docs/hf_hub.md, DEC-033).
